# 真实小说的训练集、验证集和测试集

任务：给一段小说，判断每句对白是谁说的、带什么情绪。

合成数据（上一级目录的 `train.jsonl` 等）教不会模型处理"几个人轮流说话、不写明谁说"这类句子，
所以另外从真实小说里抽片段来标注。

## 四个文件

| 文件 | 用途 | 书 | 片段 | 对白句数 |
|---|---|---|---|---|
| `train.jsonl` | 训练 | 21 本 | 920 | 7262 |
| `valid.jsonl` | 验证：训练途中打分、挑步数、比较做法 | 10 本 | 100 | 784 |
| `test.jsonl` | 测试：只在最后确认时用，不拿来挑模型 | 10 本 | 100 | 790 |
| `test_old.jsonl` | 另一个测试集，书的来源和上面三个都不同 | 13 本 | 24 | 187 |

任何一本书只出现在一个文件里。前三个文件的书来自同一个书源的 10 个题材：玄幻奇幻、修真仙侠、
都市生活、历史军事、游戏竞技、科幻末世、现代言情、古代言情、武侠、悬疑灵异。训练每个题材 2 本
（另加 1 本武侠），验证和测试每个题材各 1 本。

## 每一行

一行是一个片段：

| 字段 | 内容 |
|---|---|
| `id`、`book`、`chapter` | 片段编号、书名、章节 |
| `prompt` | 模型看到的全部内容；待标的对白前面有【编号】 |
| `lines` | 这些对白，`id` 就是编号 |
| `wider_text` | 片段前后更多的原文。只给标注的人参考，模型看不到 |
| `labels` | 每句对白的标注 |

训练集的标注：`speaker`、`emotion`，以及 `sure`（标注时有没有把握）。

验证集和测试集的标注：

- `speaker`、`emotion`：标准答案。
- `accept`：其它同样算对的说话人写法。比如同一个人的别名、称呼；无名角色的其它叫法；
  只看片段判断不出是谁时的"未知"。
- `emotion_accept`：其它同样说得通的情绪。
- `unsure`：为真表示连标注的人也判断不了，这一句不计分。

`speaker` 的特殊值："旁白"（拟声、不是人说的话），"系统"（游戏类小说里的系统提示），
"未知"，以及第一人称小说里叙述者自己的"我"。

情绪只有七种：中性、高兴、悲伤、愤怒、恐惧、厌恶、惊讶。

## 怎么来的

- 片段是用朗读时同样的切分方式从章节里抽的，所以 `prompt` 和朗读时问模型的内容一样，
  只是"已知角色"都是"暂无"。
- `train.jsonl`、`valid.jsonl`、`test.jsonl` 由 Claude Opus 5.5（低档）按 `../../labelling/` 里的说明标注，
  再用 `../../labelling/check_labels.py` 校验。拿它标了一遍 `test_old.jsonl`，和手工答案比，
  没有一句真不一致，不同的只是无名角色的叫法。
- `test_old.jsonl` 是手工标注的。

## 怎么用

```bash
# 生成训练文件：合成的 1 万条加上真实片段重复 5 次
python finetune/mix_real.py --out finetune/data/train_mixed.jsonl
python finetune/train_torch.py --out finetune/runs/名字 --grad-checkpoint --train finetune/data/train_mixed.jsonl

# 打分
python finetune/evaluate_real.py --set finetune/data/real/valid.jsonl --adapter finetune/runs/名字/step-02000
```

各个模型在这些数据上的成绩见 `../../RESULTS.md`。

## 已知的问题

- 前三个文件的书都来自同一个书源的热门榜，风格比较接近。
- 第一人称小说只有一本。
- 训练集里有 9 个片段特别长，`mix_real.py` 生成训练文件时会跳过。
- 标注是模型做的，没有逐句人工复核。
